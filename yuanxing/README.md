# 甄客行 · 燃赛文体旅城市社区（前端）

纯静态前端（原生 HTML / CSS / JavaScript），无构建步骤，无第三方依赖。当前所有数据为浏览器本地 Mock，供后端对接前的联调参考。

## 目录结构

```
index.html      入口页面（含各文件版本号 ?v=）
app.js          路由、页面渲染与所有交互逻辑
store.js        状态读写与业务校验（Mock 数据层，后端接入的替换点）
data.js         Mock 种子数据（城市/分区/用户/帖子/商家/服务/订单等）
adapters.js     外部能力适配占位（燃赛、支付、商城等，均为未接入状态）
styles.css      全部样式
assets/images/  演示图片
```

## 本地运行

无需安装。用任意静态服务器打开根目录即可，例如：

```bash
python3 -m http.server 4175
# 浏览器访问 http://127.0.0.1:4175/
```

直接双击 index.html 也可运行（部分浏览器对 file:// 有限制，建议用静态服务器）。

## 数据与持久化

- 运行时数据保存在浏览器 `localStorage`，key 为 `zhenkexing-mock-v3`。
- 清空该 key（或换浏览器）即恢复 `data.js` 初始种子数据。

## 后端对接建议

- 业务读写集中在 `store.js`：帖子发布/点赞/收藏/评论、关注、服务点赞收藏、登录、订单等方法。后端接入时以真实 API 替换这些方法的内部实现，保持返回结构一致即可，UI 层（app.js）基本不用改。
- 外部能力（燃赛跳转、支付、商城）见 `adapters.js`，目前均返回“未接入/暂未开放”状态。
- 登录为手机号 + 验证码的模拟流程，未调用真实短信与鉴权。

## 说明

- 底部导航固定为“燃 / 游 / 商 / 我”。
- “商”为商城占位页，等待统一接口接入，请勿在本前端内重建商城交易。
